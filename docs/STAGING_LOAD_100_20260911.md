# Staging exam load test — 100 students

Target: `qb-security-staging-00002-fl9` only.
Load generator: Cloud Run Job `qb-security-staging-load100`, one task, one CPU, 512 MiB, no retries, 900-second timeout.
Service capacity was not increased. Production resources and traffic were not changed.

## Workload

- One synthetic 10-minute exam with 20 multiple-choice questions.
- 100 distinct synthetic Student identities and authenticated sessions, enrolled in that exam.
- Students ramp in over approximately 30 seconds.
- Each student starts a session via API, reads its questions, saves one answer every 29 seconds, reads back session state, and submits near 590 seconds after starting.
- Database verification requires 100 submitted attempts, each with 20 correct answers and a score of 20.
- Synthetic auth sessions are revoked, synthetic users disabled, and the exam closed after the run. Exam records are retained as test evidence.

This represents 100 active exam users with think time, not 100 continuously simultaneous requests. It does not test Google login throughput, a browser renderer, video proctoring, AI generation, or 10,000 users. The submissions follow the ramp distribution over about 30 seconds rather than a single synchronized instant.

## Safety controls

The script hardcodes the staging HTTPS origin, checks its Cloud Run job name, and verifies database username, actual database identity, restricted privileges, and staging bucket configuration before creating fixtures. No real user credentials are read. Temporary session credentials remain only in process memory. Any student failure stops the workload; cleanup runs on normal failure. The job has no scheduler and cannot retry automatically.

## Initial harness correction

The first execution stopped on its first request (403) because the test client omitted its double-submit CSRF cookie. The server correctly refused it. No students started an exam. The script was corrected to send both the session-bound header and cookie; no application protections were weakened.
